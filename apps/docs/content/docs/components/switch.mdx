---
title: Switch
description: A toggle switch component.
---

## Installation

```bash
npx nikaui add switch
```

## Usage

```tsx
import { Switch } from "@/components/ui/switch"
```

## API Reference

### Switch

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `motion` | `"none" \| "snap" \| "glide" \| "spring" \| "bounce"` | inherits from `NikaMotionConfig` | Animation feel for the thumb transition |

Full prop documentation is still to come. See [Animation](/docs/guide/animation)
for the preset list and for setting a default globally with `NikaMotionConfig`.
