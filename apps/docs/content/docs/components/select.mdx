title: Select
description: A select dropdown with options.
---

## Installation

```bash
npx nikaui add select
```

## Usage

```tsx
import { Select, SelectTrigger, SelectContent, SelectItem } from "@/components/ui/select"
```

## API Reference

### SelectContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `motion` | `"none" \| "snap" \| "glide" \| "spring" \| "bounce"` | inherits from `NikaMotionConfig` | Animation feel for the listbox's enter/exit transition |

Full prop documentation is still to come. See [Animation](/docs/guide/animation)
for the preset list and for setting a default globally with `NikaMotionConfig`.
