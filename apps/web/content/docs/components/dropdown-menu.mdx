---
title: Dropdown Menu
description: A dropdown menu with items and separators.
---

## Installation

```bash
npx nikaui add dropdown-menu
```

## Usage

```tsx
import { DropdownMenu, DropdownMenuTrigger, DropdownMenuContent, DropdownMenuItem } from "@/components/ui/dropdown-menu"
```

## API Reference

### DropdownMenuContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `motion` | `"none" \| "snap" \| "glide" \| "spring" \| "bounce"` | inherits from `NikaMotionConfig` | Animation feel for the menu's enter/exit transition |

Full prop documentation is still to come. See [Animation](/docs/guide/animation)
for the preset list and for setting a default globally with `NikaMotionConfig`.
