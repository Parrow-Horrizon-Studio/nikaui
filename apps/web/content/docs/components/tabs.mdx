## Installation

```bash
npx nikaui add tabs
```

## Usage

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@/components/ui/tabs"
```

## API Reference

### TabsContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `motion` | `"none" \| "snap" \| "glide" \| "spring" \| "bounce"` | inherits from `NikaMotionConfig` | Animation feel for the panel's enter transition |

See [Animation](/docs/guide/animation) for the preset list and for setting a
default globally with `NikaMotionConfig`.
