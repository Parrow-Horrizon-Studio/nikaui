## Installation

```bash
npx nikaui add checkbox
```

## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox"
```

## API Reference

### Checkbox

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `motion` | `"none" \| "snap" \| "glide" \| "spring" \| "bounce"` | inherits from `NikaMotionConfig` | Animation feel for the checkmark draw |

See [Animation](/docs/guide/animation) for the preset list and for setting a
default globally with `NikaMotionConfig`.
