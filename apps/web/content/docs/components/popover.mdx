## Installation

```bash
npx nikaui add popover
```

## Usage

```tsx
import { Popover, PopoverTrigger, PopoverContent } from "@/components/ui/popover"
```

## API Reference

### PopoverContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `motion` | `"none" \| "snap" \| "glide" \| "spring" \| "bounce"` | inherits from `NikaMotionConfig` | Animation feel for the panel's enter/exit transition |

See [Animation](/docs/guide/animation) for the preset list and for setting a
default globally with `NikaMotionConfig`.
