## Installation

```bash
npx nikaui add skeleton
```

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"
```

## API Reference

### Skeleton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `motion` | `"none" \| "snap" \| "glide" \| "spring" \| "bounce"` | inherits from `NikaMotionConfig` | Animation feel; `none` renders a static, unanimated placeholder |

See [Animation](/docs/guide/animation) for the preset list and for setting a
default globally with `NikaMotionConfig`.
