## Installation

```bash
npx nikaui add card
```

## Usage

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from "@/components/ui/card"

export default function Example() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Card Title</CardTitle>
        <CardDescription>Card description text.</CardDescription>
      </CardHeader>
      <CardContent>
        <p>Card content goes here.</p>
      </CardContent>
      <CardFooter>
        <p>Card footer</p>
      </CardFooter>
    </Card>
  )
}
```

## Animation

Card animates in on mount by default — a fade combined with a slide up, using the `spring` preset. Pass `motion="none"` to turn that off, or another preset to change the feel:

```tsx
<Card motion="none">
  No entrance animation.
</Card>
```

See [Animation](/docs/guide/animation) for the full list of presets and how to set a default globally with `NikaMotionConfig`.

## API Reference

### Card

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `motion` | `"none" \| "snap" \| "glide" \| "spring" \| "bounce"` | inherits from `NikaMotionConfig` | Animation feel for the entrance transition |

### Sub-components

- `CardHeader` — Container for title and description
- `CardTitle` — Card heading
- `CardDescription` — Card subtitle text
- `CardContent` — Main content area
- `CardFooter` — Bottom section
